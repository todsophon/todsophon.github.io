# Minecraft chest textures

Original unmodified textures from Mojang's official Bedrock samples:
https://github.com/Mojang/bedrock-samples/tree/main/resource_pack/textures/blocks

Files: chest_front.png, chest_side.png, chest_top.png.
Downloaded October 10, 2026. Minecraft assets belong to Mojang / Microsoft and are not covered by this portfolio's code license.
The CSS maps these original textures onto separate animated chest body and lid faces.

Ender variant: ender_chest_front.png, ender_chest_side.png, ender_chest_top.png, from the same official Mojang repository.
